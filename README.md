## About This Project
This repository contains the complete practical portfolio for the **HTML and CSS Introduction Lab (BCS352)** course at Invertis University. It consists of **15 progressive lab assignments** covering:
1. **Version Control with Git:** Local repository initialization, identity configuration, commits, bare remotes, pushing, and cloning.
2. **HTML5 Fundamentals:** Semantic tags, document structures, headings hierarchy, text formatting, links, images, lists, forms, and data tables.
3. **CSS Styling & Modern Layouts:** CSS selectors, variables (`:root`), Box Model, Card UI components, scrolling boxes, Flexbox layouts, CSS Grid systems, and mobile-first responsive design using media queries.

## List of Practical Assignments

- **Assignment 1:** Starting a Git Repository (`git init`, `git config`, commits, log)
- **Assignment 2:** Pushing and Cloning a Repository (`git init --bare`, push, clone)
- **Assignment 3:** Your First HTML Page (`first.html`, `headings.html`, `text-format.html`)
- **Assignment 4:** Divs, Attributes and a Small Fix (`layout.html`, `attributes.html`, `attendance-fixed.html`)
- **Assignment 5:** Links and Images (`home.html`, `portfolio.html`, `portfolio-image.html`, alt text)
- **Assignment 6:** Types of HTML Lists (unordered `ul`, nested ordered `ol`, description `dl`)
- **Assignment 7:** About Me Page (semantic tags `<header>`, `<main>`, `<footer>`, in-page jump, `mailto:`)
- **Assignment 8:** Sign-Up Forms and Choices (POST form, linked labels, radio buttons, select dropdown)
- **Assignment 9:** Tables with Headers and Footers (`caption`, `thead`, `tbody`, `tfoot`, `scope` col/row)
- **Assignment 10:** CSS Fundamentals (inline, internal style block, linked external `style.css`)
- **Assignment 11:** Units and CSS Variables (px vs %, rem, CSS variables `var()`, `tokens.css`)
- **Assignment 12:** Box Model, Cards and Scrolling (`content-box` vs `border-box`, rounded card, `overflow: auto`)
- **Assignment 13:** Flexbox Layouts (horizontal flex navigation, centered cards, wrapping cards)
- **Assignment 14:** CSS Grid Layouts (3-column equal grid `1fr`, auto-fill gallery, `grid-template-areas`)
- **Assignment 15:** Responsive Pages with Media Queries (viewport meta, mobile-first `@media 600px`, fluid images)
